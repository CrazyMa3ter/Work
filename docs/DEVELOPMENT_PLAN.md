# Dynamic Island Desktop - 开发规划文档

## 1. 项目里程碑

### Milestone 1: 基础架构搭建 (Week 1)
**目标**: 建立可运行的 Electron + React + TypeScript 项目骨架

| 任务 | 负责人 | 工期 | 交付物 |
|------|--------|------|--------|
| 初始化项目与依赖安装 | - | 1d | package.json, 可运行空项目 |
| 配置 TypeScript 编译 | - | 1d | tsconfig.json (主/渲染/共享) |
| 配置 Vite 双进程构建 | - | 2d | vite.main.config.ts, vite.renderer.config.ts |
| 配置 ESLint + Prettier | - | 1d | .eslintrc, .prettierrc |

## 3. 技术风险与应对

| 风险点 | 影响 | 应对方案 |
|--------|------|----------|
| Windows Media Control API 限制 | 媒体控制功能不可用 | 备选方案：模拟媒体按键 |
| IDE 窗口标题格式不统一 | 解析失败 | 支持多种解析模式，可配置正则 |
| 审批系统接口不统一 | 对接困难 | 预留 Webhook + 通用 HTTP 接口 |
| 多显示器适配 | 窗口位置异常 | 获取主显示器工作区尺寸计算 |

## 4. 资源需求

### 图标资源 (由设计/用户提供)
- 状态图标: 8-12 个 (在线/离线/忙碌等)
- 模块图标: 4 个 (天气/媒体/IDE/审批)
- 天气图标: 10-15 个 (晴/阴/雨/雪等)
- 媒体图标: 6-8 个 (播放/暂停/音量等)
- IDE 图标: 4-6 个 (VS Code/IDEA 等)
- 审批图标: 4-6 个 (同意/拒绝/待办等)
- 托盘图标: 2-3 个 (正常/通知/深色模式)

### 开发环境
- Node.js >= 18
- Windows 10/11 开发机
- VS Code + ESLint 插件

## 5. 验收标准

- [ ] 应用启动后灵动岛显示在屏幕顶部中央
- [ ] 悬停/点击可展开，显示四个功能模块
- [ ] 天气模块能显示实时天气信息
- [ ] 媒体模块能控制播放并显示歌曲信息
- [ ] IDE 模块能检测并显示当前编码状态
- [ ] 审批模块能展示列表并完成同意/拒绝操作
- [ ] 系统托盘提供完整菜单功能
- [ ] 设置项可持久化保存
- [ ] 打包后的安装程序可正常安装运行
